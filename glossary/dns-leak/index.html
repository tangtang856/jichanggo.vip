什么是 DNS 泄露？原理机制与客户端本地防护配置指南

词条归档: 科学上网百科词典 更新时间: 2026-03-05

当用户开启代理软件访问外网时，网络数据本身虽然已被加密，但如果计算机在查询域名对应的 IP 地址时，依然悄悄向国内宽带运营商的本地 DNS 服务器发送查询请求，这种现象就叫做 DNS 泄露（DNS Leak）。

一、DNS 泄露的危害

  1. 浏览记录被截获：本地 ISP 虽然看不到你下载的具体内容，但能清晰记录下你在几点几分查询了解析哪个外网域名。
  2. 遭遇 DNS 投毒与污染：国内运营商的 DNS 节点对受限域名实施了污染阻断，返回一个错误的虚假 IP，导致即便挂着梯子也依然显示“网站无法访问”。

二、如何在客户端中彻底杜绝 DNS 泄露？

在现代客户端（如 Clash Verge Rev、Surge、Shadowrocket）中，请确保勾选了以下关键配置：

  • 启用 Fake-IP 模式，由客户端在本地合成虚拟 IP，彻底阻断远程解析泄露。
  • 启用 DoH (DNS over HTTPS)，所有 DNS 解析请求全部通过加密 HTTPS 隧道发送至海外知名公共 DNS（如 Cloudflare 1.1.1.1）。
