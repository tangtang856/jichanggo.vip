GitHub Copilot 在 VSCode 中连不上？排查代理设置与 SSL 证书拦截问题

发布日期: 2026-03-05 阅读时间: 7 分钟 来源: 机场Go原创专栏
核心结论速览：很多开发者开启了梯子，浏览器能上 GitHub，但 VSCode 下角的 Copilot 依然显示红色小圆圈断开。这是因为 VSCode 拥有独立的网络代理设置，且对 HTTPS 解密证书极度敏感。

一、VSCode 内置代理的正确配置步骤

  1. 打开 VSCode 设置，搜索 Http: Proxy。
  2. 填入本地代理地址：http://127.0.0.1:7890。
  3. 搜索 Http: Proxy Strict SSL，如果客户端开启了 HTTPS 解密导致证书冲突，可临时取消勾选该选项。
