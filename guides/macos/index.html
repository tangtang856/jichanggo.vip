macOS 苹果电脑科学上网配置指南：Clash Verge Rev 与系统代理设置

更新时间: 2026-03-11 阅读时间: 5 分钟 作者: 机场Go技术组

在 macOS 苹果电脑系统上，科学上网不仅要满足日常 Safari 与 Chrome 浏览，往往还需要兼顾 Terminal 终端下载、Homebrew 安装包、Docker 拉取镜像以及 Xcode 依赖同步等专业开发场景。

一、支持 Apple Silicon 架构的客户端选择

请根据您的 Mac 处理器芯片架构（可在屏幕左上角苹果图标 → 关于本机中查看）下载匹配的安装包：

  • M1 / M2 / M3 / M4 芯片：下载带有 arm64 或 aarch64 后缀的 DMG 安装包（原生运行，零性能损耗）。
  • Intel 处理器芯片：下载带有 x64 后缀的安装包。

二、macOS 安装提示“已损坏，无法打开”解决办法

由于开源客户端通常未向苹果官方缴纳高额的商业公证费用，macOS Gatekeeper 安全机制可能会拦截。处理方式如下：

  1. 打开「系统设置」→「隐私与安全性」。
  2. 滚动到“安全性”栏目，在拦截提示下方点击 “仍要打开” 并输入开机密码。
  3. 若仍无法启动，可打开终端（Terminal）输入命令：sudo xattr -rd com.apple.quarantine /Applications/Clash\ Verge.app 并回车即可解除隔离。

三、配置订阅与开启增强模式（Tun）

将机场后台的 Clash 订阅导入后，勾选「系统代理（System Proxy）」。对于程序员与终端开发者，强烈建议开启 TUN 模式（Tun Mode）。开启 TUN 模式后，系统所有层面的网络请求（包括终端 curl、git clone、npm i、pip 等）将自动无缝享受加速，不再需要在终端手动输入 export http_proxy 等环境变量。
